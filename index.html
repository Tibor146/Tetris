Extensie Installeren

Sla dit bestand op als index.html en plaats onderstaand manifest.json bestand in dezelfde map. Laad de map daarna via chrome://extensions. 

{
  "manifest_version": 3,
  "name": "Neon Tetris Arcade",
  "version": "1.0",
  "description": "Speel direct Tetris vanuit je browser.",
  "action": {
    "default_popup": "index.html",
    "default_title": "Speel Tetris"
  }
}
